# Evidence-led Witness stories

The original generic three-step animated diagrams have been replaced with specific adversarial case exhibits drawn from the recorded Java fixtures. Test Witness shows the weak, strong and unconditional passing suites. Migration Witness exposes pairwise agreement on an incorrect rounding result. CI Witness shows a locale correction whose target passes while a regression fails.

Each exhibit links to its exact existing observation, selects it in the recording and opens the command transcript. Without JavaScript the links still reach the complete static recording. There is no playback, fabricated activity or simulated execution.

The collaboration proposition is the acceptance system around a company's workflow. Pages connect the experiments to the public Blueprint work and the existing explicitly author-reported internal release case. No private implementation detail or new customer/ROI claim is published.
