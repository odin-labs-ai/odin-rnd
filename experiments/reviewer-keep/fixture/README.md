# order-desk

A small order service. An order is created with one or more lines, paid, shipped, and can be
cancelled before it ships.

- `src/service.ts` is the entry point for callers.
- `src/store.ts` keeps orders in memory.
- `src/serialize.ts` turns an order into JSON and back.
- `src/events.ts` delivers order events to subscribers, in order.
- `src/generated/http-status.ts` is generated by `npm run generate`; edit the table in
  `scripts/gen-http-status.mjs` instead.

Run the tests with `npm test` and the type check with `npm run typecheck`.
