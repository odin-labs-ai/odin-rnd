LEAK SCREEN

The site stops itself.

Everything here is built from records of private work. Before this site is published, its build reads every page and every record it carries and stops on any protected name or any canary. Nothing is published unless the scan finds nothing.

How the screen reads a page.

The list of protected terms is not in this repository. It names what must never be here: the people and companies we work for, the private repositories, our machines and hosts. Publishing that list would be the leak it guards against, so the build gets it as a secret, and only as salted hashes. The build splits every text into words, hashes every run of one to four words with the salt, and looks each up. On a hit it prints the file, the line and the first eight characters of the hash, never the word.

A canary is a random string with no meaning, planted only in private sources this site's records come from. A canary on this site means a private file was copied here whole. A canary is never accepted, whatever the reason.

The screen also stops on shapes that are not secret: a home folder path, a private network address, a local address with a port, and the shapes of keys and tokens.

It fails closed. A missing, empty or broken term set stops the build; so does a scan that reads nothing.

A known occurrence is a reviewed hit that cannot be edited away here, such as a private repository name inside a pre-registration whose bytes are pinned by hash. Each is listed in the known-occurrence list with its file, its count and why. One more occurrence is a new hit, one fewer makes the row stale, and both stop the build. The list only shrinks.

The screen is scripts/leak-gate.mjs, tested by scripts/leak-gate.test.mjs.
