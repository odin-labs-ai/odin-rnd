# Test Witness — proposed scoped pilot

Status: proposal for discussion, 20 September 2026. No engagement or measured customer outcome is implied.

## Decision and fit

Do your tests catch the failures that matter?

A small Java module whose behavior can be expressed as concrete examples.

## Buyer inputs

A trusted, runnable module; existing tests; approved expected values and representative defect scenarios.

## Deliverable

An acceptance suite, seeded-defect comparison and a portable report showing what the tests detect and miss.

## Acceptance to agree

Correct code passes; each agreed seed triggers its specified assertion; missing checks and unexplained failures remain visible.

## Proposed limit and exclusions

Proposed delivery cap: 20 engineering hours, subject to inspecting inputs and agreeing the scope. This is a planning hypothesis, not a service promise or a measured effort/savings estimate. Stop and report when the agreed cap or stop condition is reached; any extension needs a new agreement.

Excluded: Automatic test generation, exhaustive correctness, untrusted code execution and production changes.
